
# Academia de Ingeniería de Datos

Proyecto de formación práctica en Python e Ingeniería de Datos.

## Objetivo

Desarrollar habilidades profesionales en programación,
procesamiento, validación y transformación de datos.

## Tecnologías

- Python 3.13
- Visual Studio Code
- Git y GitHub

## Estructura del proyecto

- main.py: punto de entrada de la aplicación.
- operaciones.py: funciones reutilizables.
- .gitignore: archivos excluidos del repositorio.

## Funcionalidades actuales

- Cálculo del total de una venta.
- Uso de funciones y módulos.
- Ejecución desde la terminal.

## Ejecución

Crear y activar un entorno virtual de Python.

Ejecutar desde la carpeta principal:

    python main.py

## Próximos contenidos

- Manejo de archivos.
- Lectura de CSV y JSON.
- Procesamiento de datos con Pandas.
- Desarrollo de pipelines ETL.
- Integración con PostgreSQL.
